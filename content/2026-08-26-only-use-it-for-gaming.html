95.打游戏才会用I Only Use It for Gaming

2026-08-26·电脑 Computers·技能 Skills·游戏 Gaming

父亲说使用电脑是基本技能，孩子却只会用电脑打游戏。

Dad says using a computer is a basic skill, but the child only knows how to use one for games.

Speakers: A - 孩子 child | B - 父亲 father
A: 爸爸，堂哥也会用电脑？
bà bà, táng gē yě huì yòng diàn nǎo?
Dad, does my older cousin know how to use a computer too?
B: 是啊，你以后也会用的。
shì a, nǐ yǐ hòu yě huì yòng de.
Yeah. You'll learn how to use one too.
B: 以后都是基本技能了。
yǐ hòu dōu shì jī běn jì néng le.
It'll be a basic skill by then.
A: 我打游戏才会用。
wǒ dǎ yóu xì cái huì yòng.
I only know how to use it for games.
这句话有两种意思：一是只在打游戏时用电脑，但也会用电脑做别的事；二是只会用电脑打游戏，别的都不会。结合上下文，这里是第二种意思。
This line can mean two things. One is: “I only use a computer when I play games, but I also know how to use it for other things.” The other is: “I only know how to use a computer for gaming and nothing else.” Here, the context makes the second meaning clear.
